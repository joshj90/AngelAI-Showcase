Purpose

This directory provides public-facing technical documentation describing selected engineering disciplines, development practices, technologies, and research capabilities associated with Angel AI.

Technical Overview

Angel AI is an experimental wearable intelligent assistant that investigates the integration of artificial intelligence, embedded computing, multimodal sensing, and human-centered interaction.

The project combines hardware and software development with research into cognitive workload, contextual awareness, accessibility, and human performance.

Software Development Approach

The project emphasizes modular software development, maintainability, scalability, component testing, and structured technical documentation.

Development activities include hardware communication, sensor data acquisition, software integration, component validation, and experimental prototyping.

Hardware Integration

Current hardware development includes the integration and testing of inertial measurement technology using the NVIDIA Jetson Orin Nano development platform.

Additional sensing technologies are being considered for future prototype development and environmental awareness research.

Artificial Intelligence Development

Research explores the potential application of artificial intelligence to contextual awareness, environmental interpretation, adaptive information delivery, and intelligent user assistance.

These capabilities remain subject to further development and experimental validation.

Human-Centered Design

Angel AI incorporates human-centered design principles throughout the research and development process.

Design considerations include usability, accessibility, information hierarchy, cognitive workload, user control, interaction efficiency, and responsible information delivery.
